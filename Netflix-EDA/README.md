# Netflix EDA Project

This project explores a Netflix dataset using Python to understand trends in content type, release years, countries, genres, and premiere dates.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files
- `Netflix_Analysis.ipynb` - main analysis notebook
- `Netflix_Originals.csv` - dataset used for analysis

## Key Tasks
- Cleaned and prepared the dataset
- Converted date columns into proper datetime format
- Created year, month, and weekday columns
- Explored content patterns and trends
- Visualized important insights
